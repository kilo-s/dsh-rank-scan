## 流程

- A–D 每个主题一个（或几个）提交，不混在一起。每个提交跑 build + test-local（基线 425），保持全绿。
- 中间提交不升版本、不写 CHANGELOG、不拍正式截图。
- 最后一个收尾提交：版本 0.6.0、CHANGELOG（按 A–D 分组）、acceptance -SkipLive（基线 99）、截图、交接。然后一次性回报。
- 不合并、不打 tag。未跟踪的过渡交接文档不提交。

## 全局约束

- 不改 host 接口和数据口径，只改 client/parts（全部文件都可以改）。
- 书签增删改、导出、回收站的语义不变。
- 文案只改本方案写明的部分。
- 变化列「0 = 持平、— = 算不出」的语义保持不变，只改视觉。
- 颜色只用 T 里的变量，不写死色值。

## A. 视觉令牌（10-tokens.js / 20-ui-kit.js）

**A1 链接去下划线**：面板内 a 默认 text-decoration:none，hover 和 focus-visible 时才出下划线。「新标签打开」这类文字动作保留下划线，用 class rs-link-action 区分。

**A2 去掉盒子套盒子**（已授权全局修改）：

- C.card 改为无背景、只保留 1px 边框
- C.detail 改为无边框、只用 T.subtle 背景，左侧保留 accent 色条
- 卡片里的详情不再画边框

**A3 chip 降噪**：新增 C.meta（12px、T.muted、无背景），用中点串联，例如「字数 17.4万字 · 收藏 141,159」。chip 只留给状态类（待补、超 7 天、站点）和 #标签 / 夹。

**A4 字号层级**：新增 T.fs.xs = 11px；新增 C.sectionLabel（12px、600、muted）和 C.itemTitle（13px、500）；元信息用 12px muted。各处统一引用这几个令牌，不要各写一份。

**A5 间距节奏**：组内 4、行间 8、分区间 16。C.row 的 margin 改为 4px 0；新增 C.section（margin-top 16px）用于分区之间。

**A6 按钮层级**：is-primary 只用于保存、扫描这类关键动作。榜单详情卡的「在 DSH 侧栏浏览器打开」降为普通按钮。全局检查 is-primary 的所有用法，清单写进交接。

**A7 输入框和下拉框高度统一为 28px**，与 .rs-btn 对齐。

## B. 榜单页（70-board.js / 55-board-cell.js）

**B1 数字列右对齐**：isNumCol 为真的 td 和 th 都 text-align:right；表头排序按钮也右对齐，箭头放在文字左侧。

**B2 变化列**：0 仍然显示「0」但用 T.muted；「—」也用 muted。只有涨跌和「＋新」用全色。

**B3 星标**：未收藏的星只在行 hover、行内有 focus 或行已展开时显示；已收藏的始终显示。@media (hover:none) 下始终显示。这条顺带解决暗色下星标太淡的问题。

**B4 控件区**：站 / 榜 / 日期 / 排序改成「小标签在上、控件在下」的网格：grid-template-columns: repeat(auto-fill, minmax(140px, 1fr))，榜的下拉占两格。480px 宽时一行两个，不再出现「排序」单独掉到下一行。

**B5**「扫描本榜（联网）」后面的说明改为 12px muted，与按钮基线对齐。

**B6** 状态带「数据日期 … · 对比 …」用 C.sectionLabel，和表格之间留 8px。

**B7 窄屏卡片**：第一行名次 + 书名 + 作者；第二行用 C.meta 中点串取代现在的 chip，涨跌保留颜色。

## C. 书签页（60-bookmarks.js）

**C1 卡片最多三行**（900 和 480 都一样，靠 nowrap + 省略，不写 480 特判）：

1. 书名（itemTitle）+ 作者（muted）+ 右侧站点 chip
2. C.meta：「收藏 141,159 · 月票 … · 截止 10-28（3 天前）」；超 7 天、待补仍用 warn chip；「旧读数」移到详情里
3. 备注（有就显示文字，没有就显示淡色「＋ 备注」文字按钮，不再用虚线框）+ #标签 / 夹 chip

操作按钮放在第 3 行右侧，空间不够时可以换到第四行。

**C2 动作**：外露「打开」「编辑」两个 ghost 按钮；「更多」菜单里放「更新本书数据（联网）」「查看详情」、分隔线、「删除」。

**C3 排序**（只在客户端做）：筛选行加一个「排序」下拉。

- 选项：最近加入（默认，即 host 原顺序）/ 最近更新（capturedAt ↓）/ 收藏或在读 ↓ / 首次发现（firstSeen.dataDate ↓）/ 书名 ↑
- null 一律排最后
- 状态存 localStorage rank-scan-panel:bm:sort:v1
- 只对当前筛选结果排序；选择集按 bookKey；全选 = 当前筛选全部；导出「当前筛选」按当前排序的顺序
- 排序写成纯函数 sortBookmarks(list, key)

**C4 分批渲染**：超过 50 条就分批，每批 50 条，底部显示「已显示 x / y · 再显示 50 条」。筛选或排序变化时重置。全选和导出「当前筛选」基于全量筛选结果。正在编辑的项即使超出已渲染范围也必须渲染。不做窗口化，不做真分页。

**C5** 筛选结果为空时，在提示旁边放「清除筛选」按钮。

**C6** 批量选择模式下，点卡片空白处切换勾选（按钮和链接除外）；批量操作条 sticky 在面板 body 顶部。

## D. 概览页和设置页（40-overview.js / 50-settings.js）

只做套用 A 之后的收尾对齐，不改结构：分区标题改用 C.sectionLabel，分区间距改用 C.section，清理显得突兀的边框套边框。数字卡保持现状。

## E. 测试（新增 tests/ui-polish.test.mjs）

- 令牌：C.card 无背景、C.detail 无边框、存在 C.meta / C.sectionLabel / C.section、有 a 默认无下划线的样式规则
- 榜单：数字列的 th / td 右对齐；变化列为 0 时文字仍是「0」且带 muted
- 书签：sortBookmarks 五种排序 + null 排最后；分批的计数与重置；全选和导出基于全量筛选结果；正在编辑的项在第 50 条之外时仍渲染；卡片结构最多 3 个内容行
- 空筛选状态有「清除筛选」
- 受样式改动影响的旧断言按新口径修改，并在交接里逐条列出
